OOP with Turtle
------

* We use the [Python Package Index][url_pypi] to find modules that we can use in our code, for example, `prettytable`. Note that packages in PyPi don't come preinstalled with Python, you must install them with the Python package manager, `pip`.

    > :memo: Its a good idea to update the requirments.txt file each time you install a new package

    ```bash
    pip install prettytable
    pip freeze > requirements.txt
    ```

* Classes follow the *Pascal case*, example `PrettyTable`
